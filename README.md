# NoomiClone multiplayer prototype (iPhone-friendly web demo)

Это отдельный демонстрационный прототип, а не мод, встроенный в настоящую NoomiClone. Он показывает создание комнаты по коду и синхронизацию простых персонажей.

## Самый простой способ попробовать
1. Размести папку `client` как статический сайт (например, GitHub Pages) — это можно сделать из браузера iPhone, но первая настройка не совсем удобная.
2. Открой ссылку на обоих iPhone в Safari.
3. На телефоне хоста нажми **Создать комнату** и отправь код другу.
4. На втором телефоне введи код и нажми **Войти**.

## Важно
- Для регистрации PeerJS-соединения нужен интернет, даже если оба устройства в одной Wi-Fi сети.
- После установки соединения данные игры идут напрямую, когда сеть это позволяет.
- Веб-страница не может сама запустить сервер `localhost` на iPhone. Для настоящего полностью локального режима без внешнего сервиса нужен отдельный хост-процесс/приложение или компьютер в сети.
- Этот пример синхронизирует только простые фигуры на тестовом холсте; он не управляет оригинальной игрой NoomiClone.
